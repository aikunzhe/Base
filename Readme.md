## 设计过程与实现记录 (2026-01-16)

### 1. 页面结构设计
- **文件**: `index.html`
- **类型**: 移动端适配 H5 单页 (Responsive Design) (Mobile First)
- **布局**: 采用 Flexbox 垂直布局，内容居中，最大宽度限制为 480px，模拟原生 App 体验。

### 2. 功能模块实现
页面主要分为两个核心卡片区域（经过用户调整，顺序如下）：

#### A. 联系人区域 (Contact Section)
- **位置**: 页面顶部
- **功能**: 提供直接拨打电话的快捷入口。
- **设计**:
  - 使用 `<a>` 标签，通过 **JavaScript** 动态赋值 `href="tel:..."`。
  - **配置**: 电话号码统一在底部 `<script>` 标签内的 `contactConfig` 对象中配置，方便后续维护修改。
  - **团长**: 电话 `15626198780` (JS变量 `commander`)，使用 **绿色渐变** (Primary Color) 按钮。
  - **副团长**: 电话 `15914493483` (JS变量 `viceCommander`)，使用 **蓝色渐变** (Secondary Color) 按钮。
  - 按钮采用圆角药丸状 (Pill shape) 设计，增加点击交互感 (Active scale effect)。

#### B. 微信群二维码区域 (QR Code Section)
- **位置**: 页面底部
- **功能**: 展示微信群二维码，方便用户长按识别进群。
- **图片处理**:
  - 引用文件: `wechatgroup.jpg`
  - **版本控制**: 添加 `?=1` 后缀 (Query String)，防止浏览器强行缓存旧图，确保用户看到最新二维码。
  - **样式优化**: 通过 CSS 限制 `max-width: 300px`，防止原图过大撑破布局，并未图片添加圆角和边框。

### 3. 视觉样式 (UI/UX)
- **色调**: 
  - 背景色: 浅灰 `#f7f8fa`，保护视力且突显卡片内容。
  - 卡片背景: 纯白 `#ffffff`，配合轻微阴影 `box-shadow`，营造层次感。
- **字体**: 使用系统默认无衬线字体栈 (`-apple-system`, `Roboto`, etc.)，保证加载速度和原生阅读体验。
- **适配**: 添加 `<meta name="viewport" ...>` 标签，禁止用户缩放，确保在各尺寸手机屏幕上显示比例正常。

### 4. 变更日志
- **v1.0**: 初始化页面，上部为二维码，下部为电话。
- **v1.1**: 用户手动调整布局，将 **电话区域移至顶部**，**二维码移至底部**，并更新了真实的联系电话。
- **v1.2**: 电话号码改为通过 **JavaScript** 动态赋值，方便配置。
